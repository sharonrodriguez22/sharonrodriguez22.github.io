# sharonrodriguez22.github.io

Mi portfolio profesional y CV bilingüe (español/inglés) como QA Analyst & Automation.

Lo construí con [Astro](https://astro.build) y TypeScript. Todo el contenido vive en un único archivo tipado que genera ambas versiones del sitio, así los dos idiomas no se desincronizan. Cada push a `main` dispara un pipeline de GitHub Actions que compila y despliega automáticamente en GitHub Pages.

🔗 **https://sharonrodriguez22.github.io**

## Qué incluye

- Perfil profesional, experiencia y stack técnico
- Proyectos destacados con links al código y a los deploys
- Certificaciones y formación
- CV descargable en PDF (ES y EN)
- Metadatos Open Graph y JSON-LD para que el link se vea bien al compartirlo en LinkedIn o WhatsApp
